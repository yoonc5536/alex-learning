        if head.xcor() > 390 or head.xcor() < -390 \

7Pause Button MEDIUM

Press P to freeze the game, press P again to continue. Just like Chunk 12's game-over switch!

🔎 Where to look: add a screen.paused switch (like game_over), then use it in the main loop with and.

Step 1 — add this block right before the # --- Main loop --- line:

screen.paused = False

def toggle_pause():
    if screen.paused == False:
        screen.paused = True
    else:
        screen.paused = False

screen.onkey(toggle_pause, "p")

Step 2 — change the main loop to check both switches:

while True:
    screen.update()
    if screen.game_over == False and screen.paused == False:
        play_frame()
    time.sleep(screen.delay)
Try it: run it — press P mid-game. The snake freezes; press P again and it wakes up!

10Poison Berry MEDIUM

poison = turtle.Turtle()

11Golden Food TRICKY

Every 5th dot is golden and worth 3 points instead of 1!

🔎 Where to look: place_food() decides the color; eat_food() decides the points. They share two new counters: screen.food_count and screen.golden.
⚠️ Python reads top to bottom — place_food() runs once at the very start, so add the counters before the food = turtle.Turtle() line.

Step 1 — find food = turtle.Turtle() and add these two lines before it:

screen.food_count = 0
screen.golden = False

Step 2 — replace the whole place_food() function with:

def place_food():
    x = random.randint(-14, 14) * 20
    y = random.randint(-14, 14) * 20
    food.goto(x, y)
    screen.food_count = screen.food_count + 1
    if screen.food_count == 5:
        food.color("#f2c14e")
        screen.golden = True
        screen.food_count = 0
    else:
        food.color("#e4572e")
        screen.golden = False

Step 3 — replace the whole eat_food() function with:

def eat_food():
    if screen.golden == True:
        screen.score = screen.score + 3   # GOLDEN bonus!
    else:
        screen.score = screen.score + 1
    place_food()
    screen.tail_length = screen.tail_length + 1
    if screen.delay > 0.05:
        screen.delay = screen.delay - 0.005
    show_score()
Try it: run it — count your dots… 1, 2, 3, 4, GOLD! +3 points!

12Beat the Clock TRICKY

You have 60 seconds! A live countdown ticks next to your score, and time-up ends the game.

📖 New words: time.time() = the current time in seconds, so time.time() - start = seconds since start. int(47.9) throws away the decimal part → 47.

🔎 Where to look: show_score() draws the text (Chunk 10), restart() resets everything (Chunk 12), and the main loop is the heartbeat.

Step 1 — find screen.score = 0 and add this line right after it (before show_score()):

screen.start_time = time.time()

Step 2 — replace the whole show_score() function with:

def show_score():
    writer.clear()
    writer.goto(0, 260)
    seconds_left = 60 - int(time.time() - screen.start_time)
    if seconds_left < 0:
        seconds_left = 0
    writer.write("Score: " + str(screen.score) + "   Time: " + str(seconds_left),
                 align="center", font=("Arial", 20, "normal"))

Step 3 — in restart(), restart the clock too. Find these lines:

        screen.delay = 0.12
        screen.start_time = time.time()   # <-- add this line
        screen.game_over = False

Step 4 — replace the main loop with:

while True:
    screen.update()
    if screen.game_over == False:
        play_frame()
        show_score()
        if time.time() - screen.start_time > 60:
            end_game()
    time.sleep(screen.delay)
Try it: run it — watch the seconds tick down next to your score. How many points can you grab in 60 seconds?

13Runaway Food TRICKY

Too slow? The dot runs away! If you don't eat it within about 5 seconds, it jumps to a new spot.

🔎 Where to look: count frames inside play_frame() — the game runs about 10 frames per second, so 50 frames ≈ 5 seconds. Same counter pattern as the score!

Step 1 — add this line right before the # --- Main loop --- line:

screen.frames = 0

Step 2 — in play_frame(), find the wall block and add the counter right after it:

        screen.frames = screen.frames + 1
        if screen.frames == 50:
            place_food()          # too slow — the food runs away!
            screen.frames = 0
Try it: run it — chase the dot! Wait 5 seconds without eating… poof, it jumps away!
