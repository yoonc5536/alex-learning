Chunk 1

Open the Window 🪟

Goal: a black game window that stays open.

✏️ Predict first: what will you see when you run this? How do you stop the program?

A black 600×600 window titled "Snake". The while True loop never ends, so close the window to stop it.

📌 Brand-new file. Type this into snake.py — this is the whole file for now.

import turtle
import time

# --- Screen ---
screen = turtle.Screen()
screen.setup(600, 600)
screen.bgcolor("#101820")
screen.title("Snake")
screen.tracer(0)

# --- Main loop ---
while True:
    screen.update()
    time.sleep(0.1)

The Game Loop 🔁

Goal: the square moves! One frame at a time.

play_frame() plays ONE frame of the game: read the direction → move the head. The while loop calls it over and over — about 10 frames every second. (Same storyboard as Week 8!)

✏️ Predict first: press Up, then quickly press Left. What path does the square draw?

It goes up, then turns left. Try pressing Down while moving up — nothing happens. No reversing!

def move_head():
    x, y = head.xcor(), head.ycor()
    if head.direction == "up":
        head.sety(y + 20)
    if head.direction == "down":
        head.sety(y - 20)
    if head.direction == "left":
        head.setx(x - 20)
    if head.direction == "right":
        head.setx(x + 20)

def play_frame():
    if head.direction != "stop":
        move_head()

Chunk 8

The Footprint Trick 👣

Goal: a short tail follows the head — with no lists!

Here is the trick: a second turtle, the painter, tiptoes behind the head and stamps a footprint everywhere the head just was. Too many footprints? Erase the oldest one. The tail is just footprints!

📖 New words:
stamp() — the turtle stamps a copy of its shape on the ground and stays where it is.
clearstamps(1) — erases the oldest 1 stamp.
hideturtle() — hides the turtle's arrow, but its stamps stay visible.

✏️ Predict first: tail_length is 3. After 20 frames, how many footprints do you see? Why not 20?

3. Every frame adds one footprint, but the oldest gets erased whenever there are more than 3. Try changing 3 to 6 — what happens?

📌 Step 1: add this BEFORE the # --- Main loop --- line.

# --- Tail painter ---
painter = turtle.Turtle()
painter.shape("square")
painter.color("#2f7d4f")
painter.penup()
painter.hideturtle()

# --- Game state ---
screen.tail_length = 3
screen.stamp_count = 0

def grow_tail(old_x, old_y):
    painter.goto(old_x, old_y)
    painter.stamp()
    screen.stamp_count = screen.stamp_count + 1
    if screen.stamp_count > screen.tail_length:
        painter.clearstamps(1)
        screen.stamp_count = screen.stamp_count - 1

def restart():
    head.goto(0, 0)
    head.direction = "stop"
    painter.clearstamps()
    screen.stamp_count = 0
    screen.tail_length = 3

📌 Step 2: find play_frame(). Change the whole function to this:

def play_frame():
    if head.direction != "stop":
        old_x, old_y = head.xcor(), head.ycor()
        move_head()
        grow_tail(old_x, old_y)
        if head.distance(food) < 20:
            print("Yum!")
            place_food()
        if head.xcor() > 290 or head.xcor() < -290 \
                or head.ycor() > 290 or head.ycor() < -290:
            restart()
▶ Run it now. Drive around — a dark-green tail follows you! Crash into the wall — the tail is cleaned up too.
