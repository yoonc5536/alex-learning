Finish Your Snake Game 🐍

You spent 8 weeks learning Python with the turtle. Now build a real game with it — a snake that moves, eats, grows, keeps score, speeds up, and ends when you crash. Four sessions, about 35 minutes each. Everything you need is on this page. No new chapters. No classes. No lists. Every idea here comes from your 8 weeks.

Before you start

What you need

  • Python 3 — the same one you set up in Week 1.
  • A text editor — Thonny, IDLE, or VS Code. Whichever you used before.
  • This page. That is really it.

How to run your game

  1. Copy the session's code into a new file.
  2. Save it as snake.py.
  3. Run it: press Run in your editor, or type python snake.py in a terminal.
  4. A black window opens. Press an arrow key — the green square starts moving!

📖 Only 6 new words in the whole project

Each one is a single small idea. Everything else is from your 8 weeks.

  • import random → random.randint(a, b) picks a random whole number from a to b. Same pattern as import time → time.sleep().
  • stamp() — the turtle leaves a copy of its shape on the screen, like a footprint.
  • clearstamps(1) — erases the oldest footprint. clearstamps() with nothing inside erases all of them.
  • write("Hi") — the turtle writes words on the screen instead of the console.
  • hideturtle() — hides the turtle arrow so you only see what it drew or wrote.
  • head.distance(food) — measures how far apart two turtles are, in pixels.

Session 1 · about 35 min
Food appears

Your Week 8 prototype moves a square and resets at the walls. Today it gets hungry: a red dot appears, and when the square touches it, the dot jumps somewhere new.

✏️ Predict on paper (5 min)

place_food() picks x = random.randint(-14, 14) * 20. Answer before you run anything:

  1. What is the biggest x it can pick? The smallest?
  2. Why multiply by 20?

Answers: 280 and -280. Times 20 because the snake moves in 20-pixel steps, so the food always lands exactly on the snake's path.

Build — copy the whole file, save as snake.py

import turtle
import random
import time

# --- Screen ---
screen = turtle.Screen()
screen.setup(600, 600)
screen.bgcolor("#101820")
screen.title("Snake")
screen.tracer(0)

# --- Snake head (from Week 8) ---
head = turtle.Turtle()
head.shape("square")
head.color("#74bd8c")
head.penup()
head.direction = "stop"

# --- Food: a red dot that jumps to a new spot ---
food = turtle.Turtle()
food.shape("circle")
food.color("#e4572e")
food.penup()

def place_food():
    x = random.randint(-14, 14) * 20
    y = random.randint(-14, 14) * 20
    food.goto(x, y)

place_food()

# --- Controls (from Week 8) ---
def go_up():
    if head.direction != "down":
        head.direction = "up"

def go_down():
    if head.direction != "up":
        head.direction = "down"

def go_left():
    if head.direction != "right":
        head.direction = "left"

def go_right():
    if head.direction != "left":
        head.direction = "right"

screen.listen()
screen.onkey(go_up, "Up")
screen.onkey(go_down, "Down")
screen.onkey(go_left, "Left")
screen.onkey(go_right, "Right")

def move_head():
    x, y = head.xcor(), head.ycor()
    if head.direction == "up":
        head.sety(y + 20)
    if head.direction == "down":
        head.sety(y - 20)
    if head.direction == "left":
        head.setx(x - 20)
    if head.direction == "right":
        head.setx(x + 20)

# --- Main loop ---
while True:
    screen.update()
    if head.direction != "stop":
        move_head()
        if head.distance(food) < 20:
            print("Yum!")
            place_food()
        if head.xcor() > 290 or head.xcor() < -290 \
                or head.ycor() > 290 or head.ycor() < -290:
            head.goto(0, 0)
            head.direction = "stop"
    time.sleep(0.12)

✅ Try it — done when…

  • Arrow keys move the green square, and it cannot reverse directly.
  • A red dot sits somewhere on the screen.
  • Touching the dot prints Yum! and the dot jumps to a new spot.
  • The dot always lands on the grid, never halfway between steps.

Session 2 · about 35 min
A tail that grows

Now the magic trick. A second turtle — the painter — teleports to where the head just was and stamps a dark-green square. Every frame adds one footprint. When footprints outnumber the tail length, the oldest footprint is erased. Eating makes the tail length grow. No lists needed — just footprints!

✏️ Predict on paper (5 min)

tail_length = 3. The game stamps 5 footprints, erasing the oldest whenever there are more than 3. After the 5th stamp, how many footprints do you see — and which ones?

Answer: 3 — the 3 newest. The first two got erased.

Build — copy the whole file over snake.py

import turtle
import random
import time

# --- Screen ---
screen = turtle.Screen()
screen.setup(600, 600)
screen.bgcolor("#101820")
screen.title("Snake")
screen.tracer(0)

# --- Snake head ---
head = turtle.Turtle()
head.shape("square")
head.color("#74bd8c")
head.penup()
head.direction = "stop"

# --- Tail painter: jumps to where the head was and stamps a body square ---
painter = turtle.Turtle()
painter.shape("square")
painter.color("#2f7d4f")
painter.penup()
painter.hideturtle()

# --- Food ---
food = turtle.Turtle()
food.shape("circle")
food.color("#e4572e")
food.penup()

def place_food():
    x = random.randint(-14, 14) * 20
    y = random.randint(-14, 14) * 20
    food.goto(x, y)

place_food()

# --- Game state: the same trick as head.direction from Week 8 ---
screen.tail_length = 3
screen.stamp_count = 0

# --- Controls ---
def go_up():
    if head.direction != "down":
        head.direction = "up"

def go_down():
    if head.direction != "up":
        head.direction = "down"

def go_left():
    if head.direction != "right":
        head.direction = "left"

def go_right():
    if head.direction != "left":
        head.direction = "right"

def restart():
    head.goto(0, 0)
    head.direction = "stop"
    painter.clearstamps()
    screen.tail_length = 3
    screen.stamp_count = 0
    place_food()

screen.listen()
screen.onkey(go_up, "Up")
screen.onkey(go_down, "Down")
screen.onkey(go_left, "Left")
screen.onkey(go_right, "Right")

# --- Game actions ---
def move_head():
    x, y = head.xcor(), head.ycor()
    if head.direction == "up":
        head.sety(y + 20)
    if head.direction == "down":
        head.sety(y - 20)
    if head.direction == "left":
        head.setx(x - 20)
    if head.direction == "right":
        head.setx(x + 20)

def grow_tail(old_x, old_y):
    painter.goto(old_x, old_y)
    painter.stamp()
    screen.stamp_count = screen.stamp_count + 1
    if screen.stamp_count > screen.tail_length:
        painter.clearstamps(1)
        screen.stamp_count = screen.stamp_count - 1

def eat_food():
    place_food()
    screen.tail_length = screen.tail_length + 1

# --- Main loop ---
while True:
    screen.update()
    if head.direction != "stop":
        old_x, old_y = head.xcor(), head.ycor()
        move_head()
        grow_tail(old_x, old_y)
        if head.distance(food) < 20:
            eat_food()
        if head.xcor() > 290 or head.xcor() < -290 \
                or head.ycor() > 290 or head.ycor() < -290:
            restart()
    time.sleep(0.12)

Notice: restart() is new. Hitting the wall now calls it, and it cleans up the whole trail too — painter.clearstamps() with nothing inside erases every footprint.

  • A dark-green trail follows the head everywhere.
  • Eating the red dot makes the trail one square longer.
  • Hitting the wall resets the snake and erases the trail.

Session 3 · about 35 min
Score and speed

A real game keeps score — and gets harder. A writer turtle (hidden, so you only see its words) prints the score at the top. Every food also shrinks the delay a little, so the snake speeds up. The delay never drops below 0.05, or the game would become impossible.

✏️ Predict on paper (5 min)

Delay starts at 0.12 and drops 0.005 per food. After 10 foods, what is the delay? After 100 foods?

Answers: 0.07 after 10 foods. Still 0.05 after 100 — the if screen.delay > 0.05 guard stops it there.

Session 4 · about 35 min
Game over — press SPACE to play again

Last upgrade: the wall stops resetting quietly and ends the game instead. end_game() freezes the snake and writes the message. restart() gets one new line — it only runs if screen.game_over, so pressing SPACE mid-game does nothing. This is your finished game!
