🧠 How I Learn Code

Use these 4 moves every time you meet new code. This is your superpower!

1

👀 READ

Read the code, line by line. What does each line do?

2

🔮 PREDICT

Before you run it, say what you think will happen.

3

🔧 CHANGE

Change ONE small thing — one number, one word.

4

▶️ RUN & CHECK

Run it! Did it match your guess? If not, why?

🕵️ Bug Hunt game: read a script and find the bug without running it — the fastest way to get good at reading code!
🗣️ Explain-back rule: if you can't explain the code in your own words, you don't own it yet.

Get Ready

with a parent

You will do: Make your Roblox account with a parent. Check the safety settings together (chat, purchases, content). Install Roblox Studio — it's free!

Remember: never share your password, and never save a payment card in Roblox.

1

Build Without Code

no code needed!

You will make: an obby — an obstacle course where players jump across platforms and dodge lava. A real game, made of blocks only!

First: learn the Studio buttons in the Studio lesson. Then: build the obby with the Classic Obby template.

▶ Studio lesson ▶ Build an obby
2

Start Reading Code

story game

You will make: a story game — like Mad Libs! Players type their own words (a name, an animal, a place) and the story fills in the blanks.

Learn to read: variables and strings. Read each line, say what it does, change one word and predict what happens before you run it.

local story = ("The great wizard " .. name)  -- ".." joins words, like + in Python
▶ Intro to coding
3

My First Game

coin platformer

You will make: a 3D platformer — collect coins and trade them for jump power!

Learn to read: the game's scripts, line by line. Change ONE number — like the coin value or the jump power — predict what happens, then run and check.

Build it in 3 parts: ① Build a greybox world  ② Script the gameplay  ③ Polish the game.

My Second Game — Adventure Game!

a whole game with money!

You will make: an adventure game — explore the world, harvest gems, sell them for coins, and buy upgrades. It's like a simulator game!

Learn to read: if statements and functions — the new ideas here. You meet them inside the game, one at a time.

Play the finished game first (the "Adventure Game Example" on the start page) so you know what you're building!

Build With AI

you direct, AI writes

You will do: design your game on paper first. Then ask the AI Assistant for ONE function at a time — never the whole game at once.

Your job: read the code AI gives you, explain it in your own words, run it, and check it against your prediction. If it's wrong, find the bug by reading.

🤖 AI is your hands, not your brain. You are the designer!

▶ "Code with AI Assistant" (in the obby lesson)
5

Make It GOOD + Playtest

polish time!

You will do: add the fun stuff — a sound when you jump, sparkles when you grab a coin, a timer, a leaderboard. Then let your friends play and fix what confuses them.

Remember: a small game that is FINISHED beats a big game that is never done!

▶ Tutorials hub — pick what you need
6

My OWN Game! 🚀

your game, your rules

You will do: design your game on paper first — what game is it? What are the rules? What makes it fun?

Then: build it small, with AI helping. You read, check, and direct. Publish it and share it with your friends!

🎯 A good game is one your friends play for 10+ minutes and ask to play again.

⭐ What Makes a Game GREAT?

Tap each box when your game has it!

Fun in 30 seconds

The first minute already feels fun. The first 3 platforms of an obby are fun!

A reason to keep playing

Coins, upgrades, beating your record — a goal that pulls you back in.

Juice! ✨

Small reactions make a game feel alive: a sound when you jump, sparkles when you grab a coin.

Not too hard, not too easy

Easy wins first, then it slowly gets harder. Too hard = quit. Too easy = bored.

Friends tested it! 🧪

Watch your friends play. Fix what confuses them or bores them. Playtesting is how games get great.
