SPIKE Prime 자기주도 학습 운영안

Alex 로봇 기초 코스 — 부모 개입 최소화 운영 가이드

1. 목표

  • 집에 있는 SPIKE Prime으로 로봇 기초(구동·자이로·센서·제어 구조)를 Alex 스스로 익힌다.
  • 파이썬 학습 때 적용한 방식 (핵심 라인 손으로 쓰기 → 실행 예측 → 챌린지 확장)을 그대로 적용한다.
  • 부모의 역할은 초기 셋업과 환경 조성으로 제한한다.
  • 교안에 전체 파이썬 코드가 포함되어 있어 별도 사이트 검색 없이 진행할 수 있다.

2. 전체 구성 (교안: SPIKE Prime Mission Guide, 영어)

  • Phase 1 조립과 첫 이동 (Prime Lessons Unit 1–3): 미션 3개 + 미니프로젝트 로봇 댄스
  • Phase 2 센서 (Unit 5): 미션 3개 + 미니프로젝트 장애물 회피 로버
  • Phase 3 똑똑한 프로그램 (Unit 6·8): 미션 2개 + 미니프로젝트 Simon Says 게임
  • Phase 4 이동 마스터 (Unit 7·9): 미션 2개 + 캡스톤 배달 로봇
  • 총 10개 미션 + 4개 미니프로젝트. 1세션 1미션, 주 2–3회, 회당 30–45분 → 약 5–7주 분량 (자기 속도로 조절).

3. 부모의 역할 — 딱 세 가지

  • 1초기 셋업 (최초 1회, 약 1시간): SPIKE 앱 설치·허브 펌웨어 업데이트, 드라이빙 베이스 조립 동행.
  • 2질문이 오면 가이드로 돌려보내기: “가이드 몇 페이지 다시 읽어봐”. 코드를 대신 읽어주거나 고쳐주지 않기.
  • 3미니프로젝트 완성 시 시연 관람: 로봇이 요구대로 움직이면 통과 — 코드 리뷰 불필요.
※ Prime Lessons 사이트(primelessons.org → Lessons)에서 매 미션의 Python 버전 레슨을 여는 것만 확인해 주세요. 앱과 같은 세대(SPIKE 2/3) 버전을 선택하고, 코드는 반드시 레슨 PDF에 있는 것을 그대로 옮겨 적게 해 주세요.

4. 세션 진행 구조 (Alex 가이드 내 4단계 루프)

  • WRITE (손으로 쓰기, 5분): 레슨의 핵심 라인을 노트에 손으로 베껴 쓰기. 복사-붙여넣기 금지.
  • PREDICT (실행 예측, 3분): 실행 전에 라인별로 로봇이 무엇을 할지 쓰기.
  • RUN (실행·비교, 10분): 실행 후 예측과 비교. 다르면 어느 라인이 예상을 깼는지 찾기.
  • EXTEND (변형 도전, 10분): 하나만 바꿔서 새로운 동작 만들기. 바꾸기 전에 예측하기.

5. 막혔을 때 규칙 (Alex도 알고 있음)

  • 15분 규칙: 15분 고민해도 못 풀면 Prime Lessons 해당 레슨의 Solution 페이지 확인 허용.
  • 단, 본 후에는 닫고 기억으로 손으로 다시 쓰기. 해답을 보고 베껴서 실행하는 것은 금지.
  • 항상 한 번에 하나만 바꾸고 테스트하기.

6. 진도 확인법

  • 가이드 마지막 페이지 체크리스트 (미션·프로젝트별 시연 날짜 기록). HTML 버전에서는 체크 표시가 기기에 저장됩니다.
  • 미니프로젝트 4개의 시연만 보면 됩니다. 중간 미션은 Alex가 스스로 체크.
  • 한 미션에 2세션 이상 멈출 때만 부모가 Prime Lessons 해답을 함께 읽어보기.

7. 준비물

  • 노트 1권(Robot Lab Notebook), 자, 검은 전기테이프(바닥 라인용, Phase 4), 책 1권(벽 대용).
  • 로봇은 과정 내내 분해하지 않고 유지 (테스트용 플랫폼).
  • 허브 충전 상태 확인 (세션 전에 충전기에 있었는지).

8. 이 다음

  • 4개 미니프로젝트 완성 = FLL Challenge 팀 합류 시 로봇 담당으로 바로 기여 가능한 기초 완성.
  • 심화 후보: Prime Lessons Unit 10 (Competition Skills) → FLL 미션 보드 도전.
