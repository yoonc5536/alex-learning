1 · Your Mission

Three things in Snake code that confuse every beginner:

  1. ⌨️ Keys don't move the snake — they only change its direction.
  2. 🍎 Food must never land on the body — so the game re-picks until it finds a free cell.
  3. 🔄 No U-turns — reversing would crash into your own neck on the very next tick.

Spring each trap below, then learn the one-line fix.

2 · Trap 1: Keys Don't Move the Snake ⌨️

Press arrow keys (or the pad). Watch: the direction badge changes instantly — but the snake moves only when you press Next tick. Keys set the direction; the loop does the moving.

Direction: ➡️

ticks: 0
Mash keys between ticks — the snake won't care until the next tick!
# key press → only this runs:
direction = new_direction   # no moving here!

# tick → then this runs:
move_snake(direction)        # the loop moves it

3 · Trap 2: Food Must Dodge the Body 🍎

Random food could land inside your snake — unfair and invisible! So the game re-picks until the cell is free. Press Spawn food and watch each pick get judged.

picks: 0
Each ❌ is a rejected pick. Each ✅ is lunch.
food = random_cell()
while food in body:    # Program 2! linear search
    food = random_cell()  # rejected — pick again

The in keyword is your linear search from Program 2, checking the body one segment at a time.

4 · Trap 3: No U-Turns 🔄

The snake is moving right ➡️. What if you press ⬅️? The new head would land exactly on the neck — instant self-crash! So the game ignores the opposite direction.

Press "Try U-turn" — the game will refuse.
if new_direction != (-dx, -dy):  # not the opposite?
    direction = new_direction   # ok, turn
# else: ignore it!

6 · Ready for the Real Snake 🐍

Trap recap — the three one-liners that bug-proof your game:

  • ⌨️ direction = new_direction on keypress — the loop moves, keys only steer.
  • 🍎 while food in body: food = random_cell() — re-pick until free (linear search inside!).
  • 🔄 if new_direction != (-dx, -dy) — never drive into your own neck.
