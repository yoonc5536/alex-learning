💻 Program 4: The Game Loop 🔁

Alex's Algorithm Lab · Step 4 of the Snake-game algorithm path

A game is a loop that never stops — until it's game over. Every tick runs the same steps, in the same order. Programs 1, 2 and 3 all live inside this loop.

Progress: 0 / 6 sections complete

1 · Your Mission

Every video game has a heartbeat called the game loop. It repeats forever:

while True:                 # the loop never stops…
    move_snake()       # ① MOVE
    check_crash()       # ② CHECK collisions
    check_food()        # ③ CHECK food
    draw_screen()       # ④ DRAW
    wait_a_moment()    # ⏱ tick speed

One trip through all the steps = one tick. Notice something? The order is the algorithm (Program 1!): exact instructions, exact sequence. Scramble the order and the game breaks.

3 · Activity: Code It — Paper First! 📝

The loop your Snake game will really use:

while True:
    new_head = (head_x + dx, head_y + dy)
    body.insert(0, new_head)      # Program 3: queue
    if new_head in body[1:]:        # Program 2: linear search
        break                     # game over!
    if new_head == food:
        score += 1               # skip pop() → grow!
    else:
        body.pop()
    draw()                    # show it
    time.sleep(0.2)           # 5 ticks per second
  1. Trace on paper: run 2 ticks by hand with body = [(2,2),(1,2)], moving right, food at (5,5). Write the body after each tick.
  2. Speed math: time.sleep(0.2) = 5 ticks/sec. What sleep gives 10 ticks/sec? ___
  3. Break it on purpose: delete the break line. What happens when the snake crashes? (Then put it back!)
  4. Challenge: add score display — where in the loop should it update?

5 · The Full Snake Machine 🐍

You now know every algorithm your Snake game needs. Here's how they fit:

while True: Program 1: exact instructions, exact order
    body.insert(0, new_head); … Program 3: the queue
    if new_head in body[1:]: break Program 2: linear search
    if new_head == food: grow! Program 3: skip pop()
    draw(); sleep() Program 4: the loop itself

Program 1 taught you that order is everything. Program 2 gave you the search. Program 3 gave you the body. Program 4 is the heartbeat running them all, tick after tick.
