self — Talking About Yourself 🪞

Goal: learn the magic word self and add methods (actions) to a class.

Inside a class, self means THIS object — the one talking right now. When buddy barks, self is buddy. When milo barks, self is milo.

Step 2a

Dogs That Bark

Step 3b

💡 Design Note: Data or Action?

Goal: learn to think before you type.

💡 DESIGN RULE #1 — Data or Action?
When you design a class, ask about everything:
• Is it a THING the object HAS? → data → save it in __init__ (like name, color, speed).
• Is it something the object DOES? → action → make it a method (like bark(), drive()).

✏️ Sort these for a Dragon class — which are data, which are actions?
name · fire_power · fly() · roar()

Data (things it has): name, fire_power → go in __init__.
Actions (things it does): fly(), roar() → become methods.
Trick: actions are usually verbs!

Step 5c

💡 Design Note: HAS-A vs IS-A

Goal: choose the right design.

💡 DESIGN RULE #2 — HAS-A vs IS-A
• HAS-A: the object owns a turtle (self.body = turtle.Turtle()). Use when the object just uses a turtle.
• IS-A: the object is a special turtle (class SuperBall(turtle.Turtle)). Use when your object is a kind of turtle — then it gets all turtle powers for free!

✏️ Think: our snake food is a red dot that jumps to random spots. Is food a kind of turtle, or does it just use one?

IS-A! A food is a circle turtle with one extra trick (jump). Next week you will build exactly that — with the magic called inheritance. 🧬

Step 7a

Goal: a Snake that builds its own 3-piece body.

self.segments = [] — an empty lunchbox. make_snake() bakes 3 pieces at (0, 0), (-20, 0), (-40, 0) (see the -i * 20?). add_segment() builds ONE turtle piece and append()s it — week 4 in action! self.head = self.segments[0] saves piece #0 as the head.

# --- Snake ---
class Snake:
    def __init__(self):
        self.segments = []
        self.make_snake()
        self.head = self.segments[0]

    def make_snake(self):
        for i in range(3):
            self.add_segment((-i * 20, 0))

    def add_segment(self, position):
        part = turtle.Turtle()
        part.shape("square")
        part.color("#74bd8c")
        part.penup()
        part.goto(position)
        self.segments.append(part)

Goal: make the body follow the head.

Picture a conga line: each dancer steps into the spot of the dancer in front — starting from the tail! Then the head steps forward 20.

The Scoreboard Class 🏆

Goal: add the third object — and learn the pro design rule: one class, one job.

Step 8a

One Class, One Job

Goal: a Scoreboard that counts.

💡 DESIGN RULE #3 — One Class, One Job
Look at our team: Snake moves. Food jumps. Scoreboard counts. Each class has one job. If a class starts doing two jobs, split it! (Imagine a Snake class that also draws the score — messy!)

Scoreboard IS-A turtle (inherits again!). It hides its turtle arrow (hideturtle() — we only want its writing), keeps self.score, and show() rewrites the text. point() = score + 1, then show.

📌 Add this BEFORE the # --- Test drive --- line.

# --- Scoreboard ---
class Scoreboard(turtle.Turtle):
    def __init__(self):
        super().__init__()
        self.hideturtle()
        self.penup()
        self.color("white")
        self.score = 0
        self.show()

    def show(self):
        self.clear()
        self.goto(0, 260)
        self.write("Score: " + str(self.score), align="center",
                   font=("Arial", 20, "normal"))

    def point(self):
        self.score = self.score + 1
        self.show()

board = Scoreboard()

# --- Food ---
class Food(turtle.Turtle):
    def __init__(self):
        super().__init__()
        self.shape("circle")
        self.color("#e4572e")
        self.penup()
        self.jump()

    def jump(self):
        x = random.randint(-14, 14) * 20
        y = random.randint(-14, 14) * 20
        self.goto(x, y)

food = Food()

# --- Snake ---
class Snake:
    def __init__(self):
        self.segments = []
        self.make_snake()
        self.head = self.segments[0]

    def make_snake(self):
        for i in range(3):
            self.add_segment((-i * 20, 0))

    def add_segment(self, position):
        part = turtle.Turtle()
        part.shape("square")
        part.color("#74bd8c")
        part.penup()
        part.goto(position)
        self.segments.append(part)

    def move(self):
        for i in range(len(self.segments) - 1, 0, -1):
            x = self.segments[i - 1].xcor()
            y = self.segments[i - 1].ycor()
            self.segments[i].goto(x, y)
        self.head.forward(20)

    def grow(self):
        self.add_segment(self.segments[-1].position())

    def up(self):
        if self.head.heading() != 270:
            self.head.setheading(90)

    def down(self):
        if self.head.heading() != 90:
            self.head.setheading(270)

    def left(self):
        if self.head.heading() != 0:
            self.head.setheading(180)

    def right(self):
        if self.head.heading() != 180:
            self.head.setheading(0)

    def reset(self):
        for part in self.segments:
            part.goto(1000, 1000)
        self.segments = []
        self.make_snake()
        self.head = self.segments[0]

snake = Snake()
